# Ndys Chram ✦
Aesthetic charm bracelet shop, ready for GitHub Pages.

### Files
- `index.html`
- `style.css`
- `script.js`
- `products.json`
- `favicon.svg`

### GitHub Pages
Upload the files → **Settings → Pages → Deploy from a branch → main / root → Save**.

### WhatsApp
In `script.js`, replace `6280000000000` with your WhatsApp number (country code, no `+`).

### Custom domain
For a GitHub Pages custom domain, set it in **Settings → Pages → Custom domain**.
